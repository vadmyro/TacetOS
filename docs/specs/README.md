# Specifications

Precise rules the code must follow (library sorting, install flow...), written before the code.

- [detection.md](detection.md): how an iPod is found, which model it is, which volume is its music
- [device-state.md](device-state.md): what the app shows for an iPod, the operations on it, the log
- [home-screen.md](home-screen.md): the first screen of the app, its look in light and dark
- [helper.md](helper.md): the program that does every disk write, its messages, commands and refusals
- [bootloader-legacy.md](bootloader-legacy.md): the bootloader of the older iPods
- [bootloader-classic.md](bootloader-classic.md): the bootloader of the iPod Classic
- [install-wizard.md](install-wizard.md): the steps of an install and an uninstall, the backups, the resume after a cut, the report
- [install-screens.md](install-screens.md): the screens of the wizard: the window, the paths, the checks, the erase, the DFU guide, the report
- [library-rules.md](library-rules.md): how music is sorted and copied
- [theme-format.md](theme-format.md): how a theme is written
- [firmware-branding.md](firmware-branding.md): where the firmware base shows its name or logo and how each place is fixed, the plugins kept, the firmware folder of the Classic
- [update-channel.md](update-channel.md): the releases, the index of the packages, the address of the channel, the versions, the download and the update of the firmware from the home screen
- [boot-screen.md](boot-screen.md): the boot logo and how to replace it from the app, the quiet bootloader of the Classic, the language screen of the first start, the install progress on the iPod and in the app
- [health.md](health.md): the health and charge files the firmware writes, the disk and battery verdicts, the history on the computer, the Health window and the line of the card
