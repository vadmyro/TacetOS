# Roadmap

Target: **v1.0 at the end of January 2027.** Dates may move; this page is updated as milestones are reached.

| Version | What it brings | Status |
|---|---|---|
|  | Project setup: repository, app skeleton, CI on Linux, Windows and macOS | 🚧 in progress |
|  | Foundations: firmware base, model database, library rules, specs of the install formats and protocols | ⏳ |
| **v0.1** | Device detection and live state (plug, unplug, disk mode, DFU) | ⏳ |
|  | Disk image test devices + privileged helper | ⏳ |
| **v0.2** | Install and reset wizard: backup, format, firmware, bootloader, guided DFU, uninstall | ⏳ |
| **v0.3** | Our own firmware build: name, custom boot logo, update channel | ⏳ |
| **v0.4** | Music library and sync: tags, cover art, sorting rules, playlists, conversion | ⏳ |
| **v0.5** | Settings editor, fonts, menu order | ⏳ |
| **v0.6** | Themes: browser, editor with live preview, simple mode, default TacetOS theme | ⏳ |
|  | Translations (French first, then many more) | ⏳ |
|  | Windows and macOS polish | ⏳ |
| **beta** | Packages (AppImage, .deb, .rpm, Windows installer, .dmg), public beta | ⏳ |
| **v1.0** | Fixes from the beta | ⏳ |

## After 1.0

- More firmware features, one tested patch at a time
- Podcasts, disk and battery health
- Voice files generated by text-to-speech
- Scrobbling of the listening log
- Guides for flash storage mods and battery replacement
